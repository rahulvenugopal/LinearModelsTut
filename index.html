One Model to Rule Them All

Most statistics courses present t‑tests, correlations, ANOVA, and regression as unrelated tools. This course reveals the deeper structure: they are all the same model. Understanding the linear model framework makes advanced neuroscience analysis efficient including mixed models.

By the end of this course, you will be able to:

  • Command Reproducible Workflows: Confidently navigate RStudio, wrangle messy datasets using dplyr verbs, and generate publication-ready plots using ggplot2 instead of relying on fragile spreadsheets.
  • See the Matrix of Linear Models: Stop memorizing fragmented decision trees. You will understand how to build and interpret simple and multiple regressions, recognizing that t-tests, ANOVAs, and correlations are all just special cases of the same core model.
  • Control for the Real World: Successfully integrate covariates to control for confounding variables and apply robust statistical methods to handle outliers and heavy-tailed data without artificially trimming your datasets.
  • Master Hierarchical Data (LMMs): Identify when standard regression fails and successfully deploy Linear Mixed Models (LMMs) to properly analyze the nested, hierarchical, or repeated-measures data common in neuroscience.
