Data Analysis for Neuroscientists in R

A modern introduction to statistical modeling, visualisation and mixed‑effects models for neuroscience research.

10 Hours 2 Weeks 16:30 – 17:30 IST Hands‑on with R in RStudio

One Model to Rule Them All

Most statistics courses present t‑tests, correlations, ANOVA, and regression as unrelated tools. This course reveals the deeper structure: they are all the same model. Understanding the linear model framework makes advanced neuroscience analysis — including mixed models — dramatically easier.

Participants will also learn how to move from fragile spreadsheet workflows to fully reproducible analysis pipelines in R.

Learning Objectives

  • Reproducible Workflows — move from spreadsheets to scripted pipelines using modern R tools.
  • Unified Statistical Thinking — understand t‑tests, ANOVA, and correlation as special cases of regression.
  • Handling Complex Data — analyse nested neuroscience datasets using linear mixed models.
